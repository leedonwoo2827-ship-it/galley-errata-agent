# TS 속독 에이전트 (Codex OAuth)

사실·내용 검증이나 사업성 보강 같은 일은 배제하고,
**오탈자·맞춤법·띄어쓰기, 표기 일관성, 비문 제거**만을 위한 속독 도구입니다.
책으로 출판하긴 어려우나 제본교재나 인쇄용으로는 사용 가능합니다. 이 정도에 멀티유즈를 하면 저품질이 나옴을 미리 고지합니다.

PDF 한 권을 넣으면 소절(최대 20쪽)로 자동으로 나누고, 4쪽씩 끊어서 한 문장도 빠짐없이 읽은 뒤
**책 전체 정오표를 한 번에** 모아 줍니다. 쪼개는 건 놓치지 않기 위해서고, 결과는 한 파일로 나옵니다.

[JEV 개정 에이전트](https://github.com/leedonwoo2827-ship-it/jev-revision-agent)와 같은 콘솔·로그인 방식입니다.

## ■ 준비 (처음 한 번)

1. `setup.bat` 더블클릭 → JEV와 같은 Codex 로그인 (이미 JEV를 쓰는 PC면 그대로 됩니다)
2. `run.bat` 더블클릭 → 콘솔이 열립니다 (http://127.0.0.1:8766, JEV와 동시에 켜도 됩니다)
   검은 창은 끄지 말고 최소화해 두세요.

## ■ 사용법

0. 「책 넣기·단위」: 가제본 PDF 전체를 끌어다 놓기 → 소절 단위가 자동으로 잡힘 → 「단위 확정」
1. 「전체 속독·정오표」에서 「전체 판정 → 정오표 한 번에」 (밤에 돌려 두셔도 됩니다)
2. 「정오표 전체 보기」 또는 xlsx 내려받기
3. (선택) 소절을 열어 체크·수정 후 「반영」 → 전체 정오표에 확정본으로 바뀜

## ■ 무엇을 잡나

| 구분 | 내용 |
|---|---|
| 오탈자·맞춤법·띄어쓰기 | Codex가 4쪽씩 읽고 규정 근거와 함께 표시 |
| 표기 일관성 | 책 전체를 대조: 따옴표·줄표 혼용, 표·그림 번호, '1절/제1절', 목차와 본문, 참고문헌 번호 |
| 비문 | 주어·서술어 호응, 조사 오류, 끝나지 않은 문장 (확률이 높은 것만 기본 선정) |

## ■ 참고

- 문제가 많은 부분은 한 번 더 쪼개서 올려 보시기 바랍니다.
- 사람이 아직 보지 않은 항목은 '자동 선정(검토 전)'으로 표시됩니다.
- PDF 줄 끝에서 생기는 띄어쓰기는 인쇄본에 보이지 않아 정오표에서 뺍니다.

<summary>명령줄 · 폴더 (관리자용)</summary>

```
python -m tse.pipeline --toc        # workspace/00_책 의 PDF로 단위 확정
python -m tse.pipeline --all        # 전체 판정 + 전체 정오표
python -m tse.pipeline 2.1          # 소절 하나만
python -m tse.rules                 # 일관성 검사만 (몇 초)
python -m tse.export_xlsx           # 전체 정오표 다시 만들기
```

```
workspace/
  00_책/                 원본 PDF · toc.json · rules_book.json
  2.1_<제목>/            00_원고 · 02_규칙검사 · 03_판정 · 04_검토 · 05_정오표
  정오표_<책>_전체.xlsx / .html
```

새 책을 넣으면 지금 작업은 `backup/`으로 옮겨지고, 콘솔의 '이전 책'에서 다시 불러올 수 있습니다.
