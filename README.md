# TS 정오표 에이전트

통신연수 교재 가제본을 **한 번 돌리면 책 전체 정오표가 한 파일로** 나오는 속독 에이전트입니다.

- **바탕:** [jev-revision-agent](https://github.com/leedonwoo2827-ship-it/jev-revision-agent)
  - 웹 콘솔과 Codex 로그인 방식은 그대로입니다.
  - 법령 구·신 비교는 빼고, 교정 판정으로 바꿨습니다.
- **나누는 이유:** 책을 소절 단위(최대 20쪽)와 4쪽 구간으로 잘게 나눠 읽는 것은 **놓치지 않기 위해서**입니다. 결과는 마지막에 하나로 합칩니다.
- **20쪽 자르기:** 예전 pdf-20-splitter처럼 손으로 자를 필요가 없습니다. PDF 책갈피를 읽어 자동으로 나눕니다.

## 설치 · 실행

1. `setup.bat`을 한 번 실행합니다.
   - Python 가상환경, PyMuPDF·openpyxl, Codex CLI를 설치하고 ChatGPT 계정으로 로그인합니다.
   - jev와 같은 로그인이라 이미 jev를 쓰는 PC면 바로 됩니다.
2. `run.bat`을 실행하면 브라우저 콘솔(http://127.0.0.1:8766)이 열립니다.
   - jev(8765)와 동시에 켜도 됩니다.

## 쓰는 순서

1. **책 넣기 · 단위**
   - 가제본 PDF 전체를 끌어다 놓습니다.
   - 책갈피의 소절(1.1, 2.3 …)이 단위가 됩니다.
   - 절 도입부는 첫 소절에 붙고, 20쪽이 넘는 소절은 소제목 경계에서 둘로 나뉩니다(예: 3.3a / 3.3b).
   - 필요하면 **정독 배분 도우미**에 이름을 쉼표로 넣으세요. 담당자와 마감(기본 3월 31일)이 쪽수에 맞춰 채워집니다.
   - **[단위 확정]**을 누릅니다.
2. **전체 속독 · 정오표**
   - **[전체 판정 → 정오표 한 번에]**를 누릅니다. 4쪽 구간마다 약 1분 걸리므로 1권(286쪽)은 1시간 남짓입니다. 밤새 돌려 두어도 됩니다.
   - 끝나면 책 전체 정오표가 나옵니다.
     - **정오표 전체 보기 (HTML)**: 게시판·가제본 배포용
     - **`정오표_<책>_전체.xlsx`**: 시트는 정오표 · 검토 후보 · 진행 현황 · 책 전체 메모
3. **(선택) 소절별 검토**
   - 왼쪽 목록에서 소절을 열면 후보를 체크하거나 수정문구를 고칠 수 있습니다.
   - [반영 → 정오표]를 누르면 그 소절은 '검토완료'가 되고, 전체 정오표에 사람이 확정한 내용으로 들어갑니다.
   - 검토 전 소절은 수정확률 60%(비문 80%) 이상 항목이 '자동 선정(검토 전)'으로 들어갑니다.
   - 소절 화면의 **[소절 PDF]**는 그 소절만 자른 PDF입니다. 정독 담당자에게 나눠 줄 때 쓰세요.

## 무엇을 잡나

| 출처 | 내용 |
|---|---|
| **규칙** (LLM 없이, 책 전체 대조) | 따옴표 혼용(곧은/굽은), 줄표 짝(– … -), 제목의 하이픈, 표·그림 번호 누락·중복·글자 크기, 본문이 가리키는 없는 표·그림, '1절' → '제1절', 소제목 번호 건너뜀, 참고문헌에 없는 인용 번호, 인쇄 목차에만 있는 항목, 반복어, 괄호 짝 |
| **AI** (Codex, 4쪽씩) | 오탈자, 맞춤법, 띄어쓰기, 문장부호, 구간 안 표기통일, 비문 |

- **사실·내용 검증은 하지 않습니다.** 통계·기관명·법령은 사람이 정독할 때 봅니다.
- **줄끝 띄어쓰기는 뺍니다.** HWP에서 내보낸 PDF는 줄 끝 공백이 사라지기도 하는데, 인쇄본에서는 보이지 않으므로 오류가 아닙니다.
- **책 전체 메모:** 소제목 번호 체계, 인용되지 않은 참고문헌, PDF 책갈피의 '(내용없음)'처럼 편집 방침으로 한 번에 정할 일은 따로 모읍니다.

## 명령줄

```
python -m tse.pipeline --toc        # workspace/00_책 의 PDF로 단위 확정
python -m tse.pipeline --all        # 전체 판정 + 전체 정오표
python -m tse.pipeline 2.1          # 소절 하나만
python -m tse.rules                 # 규칙 검사만 (몇 초)
python -m tse.export_xlsx           # 전체 정오표 다시 만들기
python -m tse.apply decisions_2.1.json   # 서버 없이 연 검토 화면에서 내려받은 결정 처리
```

## 폴더

```
workspace/
  00_책/                 원본 PDF · toc.json(단위·담당자·마감) · rules_book.json
  2.1_<제목>/
    00_원고/             소절 PDF · 텍스트 · book.json
    02_규칙검사/         rules.json
    03_판정/             results.json · cache/ (같은 구간은 다시 부르지 않음)
    04_검토/             검토 화면 html
    05_정오표/           게시판 html · xlsx · 반영내역 md/csv · 반영본
  정오표_<책>_전체.xlsx / .html
```

새 책을 넣으면 지금 작업은 `backup/`으로 옮겨집니다. 콘솔의 '이전 책'에서 다시 불러올 수 있습니다.
